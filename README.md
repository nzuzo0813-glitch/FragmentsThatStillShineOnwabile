# Fragments That Still Shine

An interactive web edition of the memoir *Fragments That Still Shine* by **Ntantiso Onwabile**.
The whole book lives in one self-contained file, `fragments-that-still-shine.html`. It needs no build step, no server and no installs.

---


## What's inside

| Section | What it does |
|---|---|
| **Hero** | Cover artwork, title, author, "Begin reading" and "Contact info" buttons, and a contents grid for all 8 chapters |
| **Top navigation bar** | Stays on screen. Numbered buttons 1–8 jump to each chapter and highlight the one you're reading. The gold **Contact info** button scrolls to the end |
| **Chapters 1–8** | The full text, with a drop-cap opening, pull-quotes for the short standalone lines, and Previous / Next buttons at the end of each chapter |
| **Contact section** | Email, phone/WhatsApp and Instagram cards |
| **Floating buttons** | Appear after scrolling. Contact, light/dark mode toggle, back to top |
| **Progress bar** | Thin gold line across the top showing how far you've read |

### Design

The look follows the cover art: torn paper fragments held together by gold. The graphic elements are:

- The cover image as the hero background
- Faint paper shards drifting behind the text
- Gold "kintsugi" crack lines that draw themselves between chapters
- Large faded chapter numerals
- A warm ivory and gold palette, with an automatic dark mode that follows your device setting. You can also toggle it with the moon button, and the choice is remembered.

Animations switch off automatically for readers who have "reduce motion" turned on.

## Technical notes

- Plain HTML, CSS and a little vanilla JavaScript. There are no frameworks or dependencies.
- The cover image is embedded as a compressed base64 JPEG.
- The only external resource is Google Fonts, and the page still works without it.
- It works on desktop and mobile. On phones the chapter buttons scroll sideways in the top bar.
- The theme choice is saved in the browser's `localStorage` and is optional. The page works if storage is blocked.
